# 🎮 Simon Says Game

A modern and interactive **Simon Says Memory Game** built using **HTML, CSS, and JavaScript**. Test your memory by repeating an ever-growing sequence of colors. The game becomes more challenging with every level!

🚀 **[Live Demo](https://akash01082.github.io/Simon-Says-Game/)**

---

## ✨ Features

- 🧠 Classic Simon Says memory gameplay
- 🎨 Modern UI with Glassmorphism design
- 🌈 Smooth color flash animations
- 🔊 Sound effects using the Web Audio API
- 📈 Live Level & Score tracking
- 🏆 Highest Score saved using Local Storage
- 🎉 Confetti celebration every 10 levels
- ⌨️ Keyboard support (R, G, B, Y)
- 📱 Fully Responsive Design
- ⚡ Built using Vanilla JavaScript (No Frameworks)

---

## 🎮 How to Play

1. Click **Start Game**.
2. Watch the sequence of flashing colors carefully.
3. Repeat the sequence by clicking the colored buttons.
4. Each successful round adds one more color.
5. One wrong click ends the game.
6. Try to beat your highest score!
